# Munin resume

Run `munin resume --format prompt`.
From a different directory, use `munin resume --project <project-path> --format prompt`.

Treat the result as a dated compiled memory snapshot. A last recorded request or planning document may already be complete; check the current tree before acting on it. If there is no relevant project memory, say so. Use `munin brain --format prompt` for the live user ask.

Done means the answer names the project, carries forward only applicable preferences or historical context, and gives a current next step only when the evidence supports one.
