The non-negotiable receipt

Every result carries five kinds of truth. Missing truth is labeled unknown, never guessed.

Provenance

What compiled source produced the answer and which source reference supports it.

Freshness

When the source was observed and whether that age is fresh, stale, or unknown.

Sensitivity

Local-private, secret/PII flags, packetization restriction, or explicit unknown.

Warnings

Missing instrumentation, degraded sources, quality gaps, and validation failures.

Coverage

Exact found, returned, dropped, and limit counts—no silent truncation.

Execution sequence

  1. Make the protocol test fail. Prove the command is absent and the harness rejects silence.
  2. Add the lifecycle boundary. Initialize, ping, list, call, deterministic errors, protocol-only stdout.
  3. Add six typed adapters. Seed one corpus, force truncation, prove all shared receipt fields.
  4. Break both host declarations on purpose. A host gate that cannot see a bad executable is false-green.
  5. Wire the real declarations. Install, list tools, call health, uninstall, prove exact profile rollback.
  6. Run the fresh phase gate. Full GNU suite, host checks, resolver, package, strict validation.
Stop rule: Any corpus mutation, silent host pass, missing provenance, or assumed-safe sensitivity blocks the gate. Release, publish, marketplace submission, real-profile install, and push remain approval boundaries.
