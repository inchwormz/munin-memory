# Munin 0.6.0-rc.2 Local Candidate

Status: local candidate. `tag: not created; approval required`.

## What changed

- Startup memory selects dated user preferences and project history, with agent results labeled unverified.
- A named project can be resumed from another directory. Fresh, relevant planning notes appear with their path and age; completed and old notes are skipped.
- Session Brain reads the live ask, while recall filters weak matches and repeated session excerpts.
- Agent-facing recall keeps the user request and reported result while leaving shell counts in structured metadata. Project-specific objections stay in their task history instead of becoming lasting user preferences.
- Codex archived sessions are included; subagent transcripts are excluded from user memory imports.
- Ongoing sessions can add corrections and results idempotently. A bounded semantic pass reads the 120 most recently changed Codex sessions before the slower archive import.
- The Codex plugin exposes six read-only memory tools through the native host.

This candidate is local. No push, tag, release, publication, or production deployment has been made.
